# BoxesPlus - 医院管理课程PPTX生成工具

版本: 2.0.0

## 快速开始

### 安装依赖

```bash
npm install pptxgenjs coffeescript
```

### 基础使用

```coffee
boxesplus = require "./code/boxesplus.coffee"

# 方法1：中文API（推荐）
boxesplus.中文
  .开始 "课程名称"
  .封面页 "标题", "副标题"
  .章节页 "第一章", "章节标题", "章节说明"
  .列表页 "知识点", ["要点1", "要点2", "要点3"]
  .结束 "output/课程大纲.pptx"

# 方法2：诗式API（极简）
boxesplus.诗式
  .创作 "课程名称"
  .诗 ["标题", "副标题"]
  .诗 ["章节编号", "章节标题", "章节说明"]
  .诗 ["知识点", "要点1\n要点2\n要点3"]
  .完成 "output/课程大纲.pptx"

# 方法3：双侧编程（架构化）
{课程幻灯片} = boxesplus

课程 = boxesplus.双侧.开始 "课程名称"
课程
  .添加 课程幻灯片.封面 "标题", "副标题"
  .添加 课程幻灯片.章节 "第一章", "章节标题", "章节说明"
  .添加 课程幻灯片.列表 "知识点", ["要点1", "要点2"]
  .完成 "output/课程大纲.pptx"
```

## API层级

### 第一层：基础API
直接封装PptxGenJS，提供最底层的控制能力。

### 第二层：中文API
语义化封装，使用中文方法名，易于理解和使用。

**适用场景**: 一般课程PPTX生成

**核心方法**:
- `开始(标题)` - 创建新演示文稿
- `封面页(标题, 副标题)` - 添加封面页
- `章节页(编号, 标题, 副标题)` - 添加章节页
- `列表页(标题, 项目列表)` - 添加列表页
- `结束(文件名)` - 保存文件

### 第三层：诗式API
极简表达，用数组参数消除逗号，接近自然语言。

**适用场景**: 快速创作、简洁表达

**核心方法**:
- `创作(标题)` - 开始创作
- `诗(内容)` - 添加一页（自动推断类型）
- `完成(文件名)` - 保存文件

**内容格式**:
```coffee
诗 ["单行"]                    # 标题页或引用页
诗 ["标题", "副标题"]           # 封面页
诗 ["编号", "标题", "副标题"]   # 章节页
诗 ["标题", "要点1\n要点2"]     # 列表页
```

### 第四层：双侧编程API
架构化设计，类定义规则，实例填充内容。

**适用场景**: 复杂项目、团队协作、代码复用

**核心概念**:
- **类一侧**: 定义模板、规则、默认值
- **实例一侧**: 填充具体内容

**使用方式**:
```coffee
class 我的幻灯片 extends boxesplus.幻灯片
  @自定义模板: (参数) ->
    new @ 类型: "自定义", ...

课程 = boxesplus.双侧.开始 "课程名称"
课程
  .添加 我的幻灯片.自定义模板 "参数"
  .完成 "output/文件名.pptx"
```

## 在hmlectures项目中使用

### 步骤1: 引入工具

```coffee
# 在hmlectures项目中
boxesplus = require "../boxesplus/glm5reviews/notes/code/boxesplus.coffee"
```

### 步骤2: 创建课程大纲

```coffee
# 例如：创建A02战略规划课程大纲
boxesplus.诗式
  .创作 "A02战略规划课程大纲"
  .诗 ["医院战略管理课程", "从规模扩张到高质量发展"]
  .诗 ["第一模块", "战略管理导论", "建立战略思维框架"]
  .诗 ["1.1 战略管理的本质", """
    从规模扩张到高质量发展的转型
    战略思维 vs 战术思维
    战略管理闭环：战略-预算-绩效-运营
  """]
  .完成 "../boxesplus/glm5reviews/notes/output/A02课程大纲.pptx"
```

### 步骤3: 批量生成

可以编写脚本批量生成所有课程大纲：

```coffee
课程列表 = [
  { 编号: "A02", 名称: "战略规划" }
  { 编号: "B01", 名称: "组织架构" }
  { 编号: "D01", 名称: "学科建设" }
]

课程列表.forEach (课程) ->
  生成课程大纲 课程.编号, 课程.名称
```


## 最佳实践

1. **简单场景**: 使用中文API或诗式API
2. **复杂项目**: 使用双侧编程API
3. **批量生成**: 编写脚本自动化
4. **团队协作**: 使用双侧编程API统一风格
