# BoxesPlus API
# 简单易用的 PPTX 生成 DSL

## 幻灯片类型

### 1. 标题幻灯片
```
# 标题
```

### 2. 内容幻灯片
```
## 标题

- 列表项1
- 列表项2
```

### 3. 方框卡片
```
## 方框标题

{{box}}
标题: 内容
内容: 内容
{{/box}}
```

### 4. 流程图
```
## 流程图

{{flow}}
开始 -> 步骤1 -> 判断 -> 结束
步骤1: 做什么
判断: 条件?
{{/flow}}
```

### 5. 表格
```
## 表格标题

| 列1 | 列2 |
|-----|-----|
| 内容 | 内容 |
```

## 使用方法

1. 创建一个 `.md` 文件
2. 运行 `coffee boxesplus-api.coffee yourfile.md`
3. 得到 `yourfile.pptx`
