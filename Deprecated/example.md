# 医院管理课程

## 课程目标

- 掌握医疗质量管理体系的构成
- 熟悉质量管理工具与方法
- 了解患者安全目标与措施

## 质量管理体系

{{box}}
定义: 医疗质量是指医疗服务在满足患者
及其家属健康需求方面所达到的程度
内容: 
  技术质量
  服务质量
  管理质量
  环境质量
{{/box}}

## PDCA循环

{{flow}}
计划 -> 执行 -> 检查 -> 处理
计划: 制定目标和计划
执行: 实施计划内容
检查: 评估执行效果
处理: 总结经验改进
{{/flow}}

## 质量维度

| 维度 | 内容 |
|------|------|
| 结构质量 | 人员、设备、制度、环境 |
| 过程质量 | 诊疗流程、操作规范 |
| 结果质量 | 诊疗效果、患者结局 |

## 总结

- 质量管理是医院管理的核心
- 需要全员参与
- 持续改进是目标
